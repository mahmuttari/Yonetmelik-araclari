# Yonetmelik-araclari

## Musab Eder Çiftliği — IPARD başvuru paketi

Kanatlı (etlik piliç) kümesi başvurusunun bütün evrakları tek bir sayfada.
Belgeler sayfanın içine gömülüdür; açan kişi önizleyebilir ve indirebilir.

**Sayfa:** https://raw.githack.com/mahmuttari/Yonetmelik-araclari/main/index.html

Bu adres GitHub'daki `index.html` dosyasını doğru içerik tipiyle sunar.
Depoya yeni bir sürüm gönderildiğinde adres aynı kalır, sayfa yenilendiğinde
güncel hâli gelir; önbelleklemez.

### Yedek adresler

Yukarıdaki adres bir gün yanıt vermezse aynı dosyayı sunan başka aracılar:

- https://cdn.statically.io/gh/mahmuttari/Yonetmelik-araclari/main/index.html
- https://cdn.jsdelivr.net/gh/mahmuttari/Yonetmelik-araclari@main/index.html

Kalıcı çözüm GitHub Pages'tir: depo ayarlarında
**Settings → Pages → Deploy from a branch → main → / (root)** seçilirse
adres `https://mahmuttari.github.io/Yonetmelik-araclari/` olur ve aracı
servise gerek kalmaz.

### Uyarı

Depo herkese açıktır. Sayfada başvuru sahibinin adı, parsel bilgisi,
yüklenicinin firma ve vergi bilgileri ile bütün birim fiyatlar yer alır.
Sayfaya arama motorlarına girmemesi için `noindex` etiketi konulmuştur,
ancak bağlantıyı bilen herkes açabilir.
